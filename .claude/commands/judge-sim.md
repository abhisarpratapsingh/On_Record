# /judge-sim

Act as a tired reviewer with four minutes and hundreds of submissions. Open the production link
cold in a private simulated 360px phone viewport, with no prior context and a slow connection.
Within eight seconds, report only what the visible screen makes you understand, quoting visible
text only. Traverse the shortest citizen journey far enough to test whether the next action is
obvious, whether the three doors work, and whether honesty/safety are visible. Name the one
screen you would screenshot into a shortlist document; `None` is valid. Record cold-start,
legibility, tap-target, dead-end, and first-impression failures with the shortest fixes.
